# MuniClear

### A modern municipal services platform for uMhlathuze Municipality

[![.NET](https://img.shields.io/badge/.NET_8-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)](https://dotnet.microsoft.com/)
[![Angular](https://img.shields.io/badge/Angular_18-DD0031?style=for-the-badge&logo=angular&logoColor=white)](https://angular.io/)

[![Stripe](https://img.shields.io/badge/Stripe-635BFF?style=for-the-badge&logo=stripe&logoColor=white)](https://stripe.com/)
[![SignalR](https://img.shields.io/badge/SignalR-0078D4?style=for-the-badge&logo=microsoft&logoColor=white)](https://learn.microsoft.com/en-us/aspnet/core/signalr/)

**MuniClear** is a full-stack civic-tech web application that replaces the outdated uMhlathuze municipality portal with a modern, mobile-first experience. Residents can pay bills, buy prepaid electricity tokens, report infrastructure faults, and track service delivery — all from one app. Municipal staff get a command-centre admin dashboard with real-time data, bulk notifications, fault management, and financial reporting.

## 🚀 Features

### 👤 Resident Portal
| Feature | Description |
|---|---|
| **JWT Authentication** | Login with Email + SA ID Number. One-click demo login. WebAuthn biometric passkey support |
| **Account Dashboard** | Real-time balance, arrears, blocked status, IBT electricity meter with live usage |
| **Prepaid Electricity** | Buy tokens via Stripe — token generated by webhook and stored instantly to DB |
| **Airtime & Data** | Buy Vodacom, MTN, Cell C, Telkom vouchers via Stripe |
| **Municipal Payments** | Pay current balance, arrears, or general account charges |
| **Payment Plans** | Set up instalment arrangements for arrears with compliance tracking |
| **Fault Reporting** | Log faults with GPS coordinates, photo evidence, and live status tracking on Leaflet map |
| **Water & Sewer** | View RBT tariff rates, submit meter readings, receive leak detection alerts |
| **Statements** | Download monthly PDF statements generated by QuestPDF |
| **Notifications** | Real-time push notifications via SignalR. Unread badge counter |
| **Profile Management** | Edit contact details, manage WebAuthn passkey devices |

### 🛡️ Admin Portal
| Feature | Description |
|---|---|
| **Operations Dashboard** | Live KPIs — residents, monthly revenue, arrears, pending faults, collection rate, active plans |
| **Resident Management** | Search, view, block/unblock accounts with reason logging and automatic notifications |
| **Billing** | Generate municipal bills per account with automatic VAT calculation and resident notification |
| **Payment Audit** | Filter payments by date range, verify unverified payments, export full CSV |
| **Fault Command Centre** | Leaflet map with colour-coded fault markers, filter by status/category, assign to teams |
| **Broadcast Notifications** | Send push + optional Twilio SMS to all residents simultaneously |
| **Payment Plans** | Monitor instalment compliance with progress bars, mark accounts as defaulted |
| **Properties Register** | View full municipal property database with meter assignments |
| **Analytics** | Revenue trend charts, platform adoption rates, fault resolution performance |
| **Reports** | Generate and download PDF statements per account via QuestPDF |

## 🛠 Tech Stack

### Backend — `MuniClear/` & `MuniClear.Data/`
```
ASP.NET Core 8 Web API     REST + SignalR real-time hub
Entity Framework Core 8    ORM with SQLite (muni.db)
JWT Bearer Auth            Role-based (Resident / Admin)
Stripe.net                 Checkout sessions + webhook processing
Twilio                     SMS notifications
QuestPDF                   PDF statement and invoice generation
BCrypt.Net-Next            Password hashing
WebAuthn (FIDO2)           Biometric passkey authentication
```

### Frontend — `MuniClear.Angular/`
```
Angular 18                 Standalone components architecture
TypeScript                 Strict mode
SCSS                       Component-scoped styling
Leaflet.js                 Interactive fault maps (CDN)
Chart.js                   Analytics charts (CDN)
SignalR JS Client          Real-time payment and notification updates
```

## ⚡ Quick Start

### Prerequisites
- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- [Node.js 18+](https://nodejs.org/)
- [Stripe CLI](https://stripe.com/docs/stripe-cli) (for webhook forwarding)

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/MuniClear.git
cd MuniClear
```

### 2. Configure API keys

Edit `MuniClear/appsettings.json`:
```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Data Source=muni.db"
  },
  "Jwt": {
    "Key": "YourSuperSecretKeyAtLeast32CharsLong!",
    "Issuer": "MuniClear",
    "Audience": "MuniClearUsers"
  },
  "Stripe": {
    "SecretKey": "sk_test_YOUR_KEY",
    "WebhookSecret": "whsec_YOUR_WEBHOOK_SECRET"
  },
  "Twilio": {
    "AccountSid": "YOUR_ACCOUNT_SID",
    "AuthToken": "YOUR_AUTH_TOKEN",
    "PhoneNumber": "+27XXXXXXXXX"
  }
}
```

### 3. Run the API
```bash
cd MuniClear
dotnet run
# API starts at http://localhost:5026
# Swagger UI at http://localhost:5026/swagger
```

The database is created automatically on first run and seeded with **20 residents** and **10 admin users**.

### 4. Forward Stripe webhooks (separate terminal)
```bash
cd "C:\Users\YOUR_NAME\Downloads\stripe_1.37.7_windows_x86_64"
.\stripe.exe listen --forward-to http://localhost:5026/api/Payments/webhook
# Copy the whsec_... secret to appsettings.json
```

### 5. Run the Angular app
```powershell
# Add Node to PATH if needed
$env:PATH += ";C:\Program Files\nodejs"

cd MuniClear.Angular
npm install
ng serve
# App starts at http://localhost:4200
```

## 📡 API Reference

Base URL: `http://localhost:5026/api`

| Controller | Endpoints | Auth |
|---|---|---|
| `Auth` | `POST /Auth/login`, `POST /Auth/demo`, `POST /Auth/passkey/login` | Public |

| `ElectricityPurchases` | `GET /ElectricityPurchases/account/{id}` | Bearer |

## 💳 Payment Flow

```
Resident clicks "Pay" → Angular calls POST /Payments/create-checkout/{id}
       ↓
API creates Stripe Checkout Session with metadata (AccountId, PaymentType, MeterNumber)
       ↓
Browser redirects to Stripe hosted checkout page
       ↓
Resident completes payment on Stripe
       ↓
Stripe fires POST /Payments/webhook (AllowAnonymous)
       ↓
Webhook handler:
  • Saves Payment record to DB
  • If Electricity: generates xxxx-xxxx-xxxx-xxxx-xxxx token → saves ElectricityPurchase
  • If Airtime: generates 13-digit voucher → saves MobilePurchase
  • If Arrears-Unblock: reduces ArrearsBalance → unblocks account → sends Twilio SMS
  • Broadcasts SignalR event to all connected clients
       ↓
Stripe redirects browser to /electricity?success=true
       ↓
Angular detects ?success=true → polls DB → displays new token
```

## ⚡ IBT Electricity Tariff (uMhlathuze 2026)

| Block | Range | Rate (excl. VAT) | Rate (incl. 15% VAT) |
|---|---|---|---|
| Block 1 | 0 – 50 kWh | R 0.85/kWh | R 0.98/kWh |
| Block 2 | 51 – 350 kWh | R 1.32/kWh | R 1.52/kWh |
| Block 3 | 351 – 600 kWh | R 1.89/kWh | R 2.17/kWh |
| Block 4 | 600+ kWh | R 2.45/kWh | R 2.82/kWh |

**Arrears diversion rule:** When an account is blocked, 30% of all electricity payments are automatically redirected to clear the arrears balance before crediting the account.

## 💧 Water RBT Tariff (uMhlathuze 2026)

| Block | Range | Rate |
|---|---|---|
| Free basic | 0 – 6 kL | FREE |
| Block 2 | 7 – 15 kL | R 12.65/kL |
| Block 3 | 16 – 30 kL | R 18.97/kL |
| Block 4 | 31 – 60 kL | R 28.46/kL |
| Block 5 | 60+ kL | R 42.69/kL |

Sewer = 65% of water charge · Refuse = R185.50/month · All charges + 15% VAT
